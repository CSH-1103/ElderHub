# 13 膳食管理（预留模块）

> 涉及代码：`entity/Food|Meal|CustomerPreference`、`service/FoodService|MealService|CustomerPreferenceService(+impl)`、`mapper/FoodMapper|MealMapper|CustomerPreferenceMapper`、`sql/16~18`

## 1. 功能概述

膳食模块当前只完成了**数据层与表结构**：食品信息、膳食日历、客户饮食喜好。三个 Service 均为 MyBatis-Plus 空实现（仅继承 `ServiceImpl`），**没有编写 Controller，未对外提供接口**，属于预留/待开发模块。

## 2. 已有代码结构

| 分层 | 文件 | 状态 |
| --- | --- | --- |
| 实体 | `Food`、`Meal`、`CustomerPreference` | 已完成（字段与表对应） |
| Mapper | `FoodMapper`、`MealMapper`、`CustomerPreferenceMapper` | 已完成（无自定义 SQL） |
| Service | `FoodService/Impl`、`MealService/Impl`、`CustomerPreferenceService/Impl` | 空实现（可用 MP 通用 CRUD） |
| Controller | 无 | 待开发 |

## 3. 数据表

### 3.1 `food` 食品信息表（16_biz_food.sql）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 主键，自增 |
| `food_name` | varchar(30) | 食品名称 |
| `food_type` | varchar(30) | 食品分类 |
| `price` | decimal(10,2) | 价格 |
| `is_halal` | int | 是否清真（0 否 / 1 是，默认 0） |
| `food_img` | varchar(100) | 图片路径 |

### 3.2 `meal` 膳食日历表（18_biz_meal.sql）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 主键 |
| `week_day` | varchar(10) | 星期几 |
| `meal_type` | int | 餐次（1 早餐 / 2 午餐 / 3 晚餐） |
| `food_id` | int | 食品 ID |
| `taste` | varchar(30) | 口味要求（少糖/少盐等） |
| `is_deleted` | int | 逻辑删除（默认 0） |

### 3.3 `customer_preference` 客户饮食喜好表（17_biz_customer_preference.sql）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 主键 |
| `customer_id` | int | 客户 ID |
| `preferences` | varchar(30) | 饮食喜好 |
| `attention` | varchar(30) | 忌口注意事项 |
| `remark` | varchar(30) | 备注 |
| `is_deleted` | int | 逻辑删除（默认 0） |

## 4. 后续开发建议

1. 新建 `controller/FoodController`、`MealController`、`CustomerPreferenceController`，沿用统一 `Result` 与分页规范；
2. 膳食日历建议提供"按周查询"接口（`meal` 与 `food` 联查返回菜名/价格）；
3. 客户饮食喜好可按 `customer_id` 维护（一客户一条，保存前查重）。
