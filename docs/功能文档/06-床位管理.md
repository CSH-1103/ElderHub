# 06 床位管理

> 涉及代码：`controller/BedController`、`service/BedService(+impl)`、`service/BedDetailsService(+impl)`、`service/RoomService(+impl)`、`entity/Bed|BedDetails|Room`、`dto/BedTransferDTO|BedDetailsQuery`、`vo/BedVO|BedStatisticsVO|BedDetailsVO|RoomVO|RoomBedVO`

## 1. 功能概述

管理房间与床位：床位统计、床位示意图（按楼层/房间分组）、床位使用详情（正在使用/使用历史）、床位调换、空闲床位查询。

床位状态：`1 空闲`、`2 已入住`、`3 外出`。

## 2. 接口清单

基础路径：`/admin/bed`

| 方法 | 路径 | 说明 | 入参 | 返回 data |
| --- | --- | --- | --- | --- |
| GET | `/statistics` | 床位统计 | - | `BedStatisticsVO` |
| GET | `/map` | 床位示意图（不传楼层默认第一层） | `floor`（可选） | `List<RoomBedVO>` |
| GET | `/details/list` | 床位使用详情分页 | Query：`customerName`、`roomNo`、`startDate`、`status`(默认 1)、`pageNum=1`、`pageSize=10` | `PageResult<BedDetailsVO>` |
| PUT | `/details/update` | 修改使用详情（仅 endDate） | Query：`id`、`endDate`(yyyy-MM-dd) | - |
| POST | `/transfer` | 床位调换 | JSON：`BedTransferDTO` | - |
| GET | `/room/list` | 房间列表（按楼层、房号排序） | - | `List<RoomVO>` |
| GET | `/free/{roomNo}` | 按房间号查空闲床位 | 路径 `roomNo` | `List<BedVO>` |

## 3. 核心业务逻辑（BedServiceImpl）

### 3.1 床位统计 `getBedStatistics`

总数（count）+ 按状态计数（空闲/已入住/外出），返回 `BedStatisticsVO`。

### 3.2 床位示意图 `listBedMap(floor)`

1. 未传 `floor` → 取楼层最小的第一条房间的 `room_floor` 作为默认；
2. 查该楼层全部房间（按 `room_no` 升序）；
3. 查这些房间的全部床位（按 `room_no、bed_no` 升序）并按房间分组；
4. 组装 `RoomBedVO`（房间 + 床位列表）。

### 3.3 使用详情 `listBedDetails`

- 过滤条件：`customerName`（子查询 `customer_id IN (SELECT id FROM customer WHERE customer_name LIKE ...)`）、`roomNo`（子查询 `bed_id IN (SELECT id FROM bed WHERE room_no=...)`）、`startDate`、`status`；
- `status=1 正在使用`：`is_deleted=0 AND (end_date IS NULL OR end_date > now)`；
- `status=2 使用历史`：`is_deleted=1 OR end_date <= now`；
- 按 `id` 倒序分页后，批量补齐客户名、床位号、房间号，逐条计算状态（`isInUse`：未删除且未结束）与状态文案（"正在使用"/"使用历史"）。

### 3.4 修改使用详情 `updateBedDetailsEndDate`

校验记录存在、`endDate` 不早于 `start_date`，仅更新 `end_date`。

### 3.5 床位调换 `transferBed`（事务）

1. 校验客户存在、客户有床位；若传了 `oldBedId` 必须与客户当前床位一致；
2. 校验目标床位存在、状态为**空闲**、且不等于当前床位；
3. 旧 `bed_details`：`end_date = 今天` 且 `is_deleted = 1`；
4. 新建 `bed_details`：`start_date = 今天`、`end_date = null`、`bed_details = 入参说明`；
5. 旧床 `bed_status = 1`（空闲）、新床 `bed_status = 2`（已入住）；
6. 更新客户：`room_no`（新床位房间号字符串）、`bed_id`、`building_no = "606"`（固定楼栋）。

### 3.6 房间与空闲床位

- `listRooms`：全部房间按楼层、房号升序转 `RoomVO`；
- `listFreeBeds(roomNo)`：该房间 `bed_status=1` 的床位，按 `bed_no` 升序转 `BedVO`。

## 4. 数据表

| 表 | 字段 |
| --- | --- |
| `room` | `id、room_floor、room_no` |
| `bed` | `id、bed_no、room_no、bed_status(1/2/3)、remarks` |
| `bed_details` | `id、bed_id、customer_id、start_date、end_date、bed_details、is_deleted` |

## 5. 注意事项

1. 楼栋固定值 `606` 仅在床位调换时写入客户表；
2. 使用详情分页的 `startDate` 过滤为精确日期（`eq`），不是范围；
3. `BedDetails` 的删除状态由 `is_deleted` 手工维护（删客户/调换时置 1），项目未启用 MP 逻辑删除。
