# 14 公共组件与配置

> 涉及代码：`common/`、`exception/`、`utils/`、`interceptor/`、`annotation/`、`config/`、`dto/UserContext|LoginUser`、`resources/application.yml`、`ElderHubApplication`

## 1. 统一响应 Result（`common/Result.java`）

| 方法 | 说明 |
| --- | --- |
| `success(data)` / `success()` | `{code:200, message:"success", data}` |
| `error(message)` | `{code:500, message, data:null}` |
| `error(code, message)` | 自定义 code |

响应字段：`code、message、data`（注意：不是设计文档中的 `msg`）。

## 2. 全局异常处理（`exception/GlobalExceptionHandler.java`）

| 异常 | 返回 |
| --- | --- |
| `IllegalArgumentException` | `code=400`，message 为异常消息 |
| 其他 `Exception` | `code=500`，message 固定 `"Internal server error"`（不泄露细节） |

> 注意：业务代码大量使用 `RuntimeException`，走的是 500 分支且消息被替换成 `"Internal server error"`；部分 Controller（如客户管理）自己在 catch 中转成 `Result.error(e.getMessage())` 返回 500。若要前端展示业务错误消息，建议改为 `BusinessException` + 400 分支。

## 3. JWT 与登录态（详见 01 文档）

| 组件 | 说明 |
| --- | --- |
| `utils/JwtUtil` | 签发/解析/校验 Token（jjwt，HS256）；参数 `jwt.secret`、`jwt.expiration-ms` |
| `annotation/RequireLogin` | 方法级注解，标注后才校验登录 |
| `interceptor/JwtInterceptor` | 注册在 `/**`，只校验带注解的方法；校验失败返回 401 JSON；成功后写入 `UserContext` |
| `dto/UserContext` | `ThreadLocal<LoginUser>`（`set/get/clear`） |
| `dto/LoginUser` | `userId(Long)、username(String)` |
| `utils/MD5Util` | MD5 工具（当前业务未使用；密码使用 BCrypt） |

## 4. 配置类（`config/`）

| 配置类 | 作用 |
| --- | --- |
| `MybatisPlusConfig` | `@MapperScan("com.it.elderhub.mapper")`；注册 `PaginationInnerInterceptor`（MySQL 分页） |
| `WebMvcConfig` | 注册 `JwtInterceptor`，拦截 `/**` |
| `CorsConfig` | `CorsFilter`：允许所有来源、方法（GET/POST/PUT/DELETE/OPTIONS）、所有请求头，`allowCredentials=true` |
| `SwaggerConfig` | OpenAPI 信息（标题 `ElderHub 后端接口文档`，版本 1.0）；UI 默认 `/swagger-ui.html` |
| `SecurityConfig` | 提供 `BCryptPasswordEncoder` Bean |

```yaml
server:
  port: 8080
  servlet:
    context-path: /ElderHub
spring:
  application.name: elder-hub
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/elderhub?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: 123456
  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: Asia/Shanghai

  mapper-locations: classpath*:mapper/**/*Mapper.xml
  configuration:
    map-underscore-to-camel-case: false
  global-config:

      id-type: auto
      table-prefix: t_

```

## 6. 启动类

`ElderHubApplication`：`@SpringBootApplication + @MapperScan("com.it.elderhub.mapper")`，启动后打印"颐养中心系统启动成功"。

## 7. 公共规范与注意事项

1. **命名约定**：实体字段沿用下划线命名（如 `customer_name`），DTO/VO 用驼峰；`map-underscore-to-camel-case: false`，因此实体字段名必须与列名一致；
2. **逻辑删除**：项目**没有**启用 MyBatis-Plus 逻辑删除（无 `@TableLogic`、无全局配置），各业务自行用 `is_deleted` 字段手工处理；`removeById/deleteById` 是物理删除，编码时要留意；
3. **CORS**：`allowCredentials=true` 与 `allowedOrigins="*"` 组合在 Spring 中会触发校验异常，联调时建议改为具体前端域名（如 `http://localhost:5173`）或关闭凭证；
4. `table-prefix: t_` 对显式 `@TableName` 的实体不生效，表名以实体注解为准；
5. 日期字段混用 `java.util.Date`、`java.time.LocalDate`、`LocalDateTime`，Jackson 已统一输出 `yyyy-MM-dd HH:mm:ss`。
