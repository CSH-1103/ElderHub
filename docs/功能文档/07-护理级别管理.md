# 07 护理级别管理

> 涉及代码：`controller/NurseLevelController`、`service/NurseLevelService(+impl)`、`service/NurseLevelItemService(+impl)`、`entity/NurseLevel|NurseLevelItem|NurseContent`

## 1. 功能概述

管理员维护护理级别（如一级护理、二级护理），并为每个级别配置包含的护理项目。级别与项目为多对多关系（`nurse_level_item`）。

## 2. 接口清单

基础路径：`/admin/nurse-level`

| 方法 | 路径 | 说明 | 入参 | 返回 data |
| --- | --- | --- | --- | --- |
| GET | `/list` | 分页查询（默认查全部未删除） | `pageNum=1`、`pageSize=10`、`levelStatus`（可选） | `IPage<NurseLevel>` |
| POST | `/save` | 新增级别 | JSON：`NurseLevel` | - |
| PUT | `/update-status` | 修改状态（启用/停用） | Query：`id`、`levelStatus`(1 启用 / 2 停用) | - |
| GET | `/items/{levelId}` | 查某级别已配置项目 | 路径 `levelId` | `List<NurseContent>` |
| POST | `/item/save` | 给级别添加项目 | Query：`levelId`、`itemId` | - |
| DELETE | `/item/remove/{levelId}/{itemId}` | 移除级别下项目 | 路径参数 | - |

## 3. 核心业务逻辑（NurseLevelServiceImpl）

### 3.1 分页查询 `listLevels`

条件：`is_deleted=0`；可选 `level_status` 精确匹配；按 `create_time` 倒序。

### 3.2 新增 `saveLevel`

- `level_status` 为空默认 `1`（启用）；
- `is_deleted=0`，`create_time/update_time = now`；
- 直接插入（不对级别名做重名校验）。

### 3.3 修改状态 `updateLevelStatus`

仅更新 `level_status` 与 `update_time`。

### 3.4 级别项目维护

- `listLevelItems(levelId)`：先查 `nurse_level_item` 关联，再按 `item_id` 批量查 `nurse_content`（仅未删除），按 `create_time` 倒序返回；
- `saveLevelItem(levelId, itemId)`：
  1. 校验项目存在且未删除、`status=1`（启用），否则抛异常（`护理项目不存在` / `该护理项目已停用，不能添加`）；
  2. 校验该级别未配置过该项目（防重复）；
  3. 插入关联记录；
- `removeLevelItem(levelId, itemId)`：按条件删除关联记录（物理删除）。

## 4. 数据表

| 表 | 字段 | 说明 |
| --- | --- | --- |
| `nurse_level`（实体 `NurseLevel` → `@TableName("nurselevel")`） | `id、level_name、level_status(1启用/2停用)、is_deleted、create_time、update_time` | 护理级别 |
| `nurse_level_item`（实体 `NurseLevelItem` → `@TableName("nurselevelitem")`） | `id、level_id、item_id` | 级别-项目关联 |
| `nurse_content` | 见 08 文档 | 护理项目 |

## 5. 注意事项

1. 实体 `@TableName` 值为 `nurselevel`、`nurselevelitem`（无下划线），而 `sql/` 脚本建的表名为 `nurse_level`、`nurse_level_item`；部署时需要统一（改注解或改表名），当前以实际数据库为准；
2. 级别表 DDL 中 `create_time/update_time` 列在 `sql/10_biz_nurse_level.sql` 中未定义，但服务会写入这两个字段，需要同步补充列或调整代码；
3. 删除关联为物理删除；级别本身未见删除接口。
