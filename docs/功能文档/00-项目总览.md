## 5. 统一响应格式

所有接口返回 `Result<T>`（`common/Result.java`）：

```json
{ "code": 200, "message": "success", "data": {} }
```

- `code=200` 成功；`code=400` 参数错误（`GlobalExceptionHandler` 捕获 `IllegalArgumentException`）；
- `code=500` 其他异常（统一返回 `"Internal server error"`，不透出堆栈）。

## 7. 认证与角色（详见 01）

- 登录：`POST /auth/login` → 返回 `token`（JWT，payload：`sub=用户ID`、`username`、`roleName`）。
- 校验：`JwtInterceptor` 只拦截标注了 `@RequireLogin` 的接口；当前仅 `/auth/logout` 标注。
- 角色：`role_id=1` 管理员（ADMIN）、`role_id=2` 健康管家（USER，取 `role.name`）。
- 管理员接口统一前缀 `/admin/**`，管家接口统一前缀 `/nurse/**`。
