# 08 护理项目管理

> 涉及代码：`controller/NurseContentController`、`service/NurseContentService(+impl)`、`entity/NurseContent`、`entity/NurseLevelItem`

## 1. 功能概述

管理员维护护理项目（如晨间护理、口腔护理）：项目编号、名称、价格、描述、执行周期/次数、启停状态。停用或删除项目时会自动清理"级别-项目"关联。

## 2. 接口清单

基础路径：`/admin/nurse-content`

| 方法 | 路径 | 说明 | 入参 | 返回 data |
| --- | --- | --- | --- | --- |
| GET | `/list` | 分页查询 | `pageNum=1`、`pageSize=10`、`status`（可选）、`nursingName`（模糊，可选） | `IPage<NurseContent>` |
| POST | `/save` | 新增项目 | JSON：`NurseContent` | - |
| PUT | `/update` | 修改项目 | JSON：`NurseContent`（含 id） | - |
| DELETE | `/remove/{id}` | 删除项目 | 路径 `id` | - |

## 3. 核心业务逻辑（NurseContentServiceImpl）

### 3.1 分页查询 `listContents`

条件：`is_deleted=0`；`status` 精确匹配；`nursingName like`；按 `create_time` 倒序。

### 3.2 新增 `saveContent`

- `status` 为空默认 `1`（启用）；
- `is_deleted=0`，`create_time/update_time = now`。

### 3.3 修改 `updateContent`（事务）

1. 校验 `id` 非空；
2. 更新 `update_time` 后 `updateById`；
3. **若状态被改为 2（停用）**：自动删除 `nurse_level_item` 中所有该 `item_id` 的关联记录（物理删除）。**不影响**客户已购的 `customer_nurse_item`。

### 3.4 删除 `removeContent`（事务）

1. 先删除 `nurse_level_item` 中该项目的全部关联记录（物理删除）；
2. 再将 `nurse_content.is_deleted = 1` 并更新 `update_time`（手工逻辑删除）。

## 4. 数据表

`nurse_content`（09_biz_nurse_content.sql）：

| 字段 | 说明 |
| --- | --- |
| `id` | 主键 |
| `serial_number` | 项目编号（如 HL001） |
| `nursing_name` | 项目名称 |
| `service_price` | 服务价格（decimal(10,2)） |
| `message` | 项目描述 |
| `execution_cycle` | 执行周期 |
| `execution_times` | 执行次数 |
| `status` | 1 启用 / 2 停用（默认 1） |
| `is_deleted` | 0 正常 / 1 删除（默认 0） |

## 5. 注意事项

1. 实体 `NurseContent` 的 `@TableName("nursecontent")`、字段 `service_price` 为 `Integer`，与 DDL 的表名 `nurse_content`、`decimal(10,2)` 价格存在差异，需要统一（价格建议用 `BigDecimal`）；
2. 实体包含 `create_time/update_time` 且服务会写入，而 DDL 未定义这两列，需要补充；
3. 停用与删除均不影响客户已购买的项目记录（`customer_nurse_item`）。
