# 02 用户管理

> 涉及代码：`controller/UserController`、`controller/RoleController`、`controller/MenuController`、`service/UserService(+impl)`、`entity/User|Role|Menu|RoleMenu`、`dto/UserAddDTO|UserUpdateDTO|UserQuery`、`vo/UserVO`

## 1. 功能概述

管理员对系统用户（含健康管家）进行增删改查；提供角色列表与菜单树供前端配置使用。

## 2. 接口清单

基础路径：`/admin/user`

| 方法 | 路径 | 说明 | 入参 | 返回 data |
| --- | --- | --- | --- | --- |
| GET | `/list` | 分页查询用户 | Query：`nickname`(模糊)、`roleId`、`pageNum=1`、`pageSize=10` | `IPage<UserVO>` |
| GET | `/{id}` | 用户详情 | 路径 id | `UserVO` |
| POST | `/save` | 新增用户 | JSON：`UserAddDTO` | - |
| PUT | `/update` | 修改用户 | JSON：`UserUpdateDTO` | - |
| DELETE | `/remove/{id}` | 删除用户（置 `is_deleted=1`） | 路径 id | - |
| GET | `/nurse-list` | 管家列表（`role_id=2`） | `nickname`（可选） | `List<UserVO>` |
| POST | `/login` | 兼容接口（直接返回字符串"登录成功/失败"） | JSON：`User` | 字符串 |

辅助接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/admin/role/list` | 角色列表（未删除） |
| GET | `/admin/menu/tree` | 全量菜单列表（前端自行组树） |

## 3. 核心逻辑（UserServiceImpl）

### 3.1 分页查询

`listUsers(UserQuery)`：条件 `is_deleted=0`，`nickname like`、`roleId eq`；分页后逐条 `convertToVO` 填充 `roleName`（按 `role_id` 查 `role` 表）。

### 3.2 新增 / 修改 / 删除

- `saveUser(UserAddDTO)`：`BeanUtils.copyProperties` 到 `User`，置 `is_deleted=0`、`create_time=now`，直接 `save`。
- `updateUser(UserUpdateDTO)`：拷贝属性后置 `update_time=now`，`updateById`。
- `removeUser(id)`：查出后置 `is_deleted=1`、`update_time=now`，`updateById`（手工逻辑删除）。

### 3.3 其他

- `listNurses(nickname)`：`role_id=2` 且 `is_deleted=0`，昵称模糊匹配。
- `listRoles()`：`role` 表 `is_deleted=0`。
- `listMenuTree()`：直接 `selectList(null)` 返回全部菜单（不做组装）。

## 4. 数据表

| 表 | 字段 | 说明 |
| --- | --- | --- |
| `user` | `id、nickname、username、password、sex、email、phone_number、role_id、create_time、create_by、update_time、update_by、is_deleted` | 系统用户；`role_id`：1 管理员 / 2 健康管家 |
| `role` | `id、name、create_time、update_time、update_by、is_deleted` | 角色 |
| `menu` | `id、menus_index、title、icon、path、parent_id` | 菜单路由 |
| `role_menu` | `id、role_id、menu_id` | 角色-菜单关联（当前无接口维护） |

## 5. 注意事项

1. `saveUser` 直接保存明文密码（代码 TODO：后续加密），与注册接口（BCrypt）不一致；
2. `User` 实体的字段名为下划线风格（如 `role_id`），而 `UserVO/UserAddDTO` 为驼峰（`roleId`、`phoneNumber`），`BeanUtils.copyProperties` 可正常映射；
3. `user` 表 DDL 中 `create_by` 为 NOT NULL，新增用户未写入该字段，建库时建议给默认值或代码补充；
4. `/admin/user/login` 为遗留调试接口，返回纯文本，不属于统一 `Result` 规范。
