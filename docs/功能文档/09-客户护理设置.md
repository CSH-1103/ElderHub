# 09 客户护理设置

> 涉及代码：`controller/CustomerNurseItemController`、`service/CustomerNurseItemService(+impl)`、`entity/CustomerNurseItem|NurseLevelItem|NurseContent`、`dto/CustomerNurseItemAddDTO`、`vo/CustomerNurseItemVO`

## 1. 功能概述

管理员为客户设置护理级别（自动绑定级别下所有项目）、单独购买护理项目、续费、移除；并查询客户已购项目及状态。

## 2. 接口清单

基础路径：`/admin/customer`

| 方法 | 路径 | 说明 | 入参 | 返回 data |
| --- | --- | --- | --- | --- |
| POST | `/`（本控制器未写子路径） | 设置护理级别 | **请求体为纯数字** `customerId` + Query `levelId` | - |
| DELETE | `/level/remove/{customerId}` | 移除护理级别 | 路径 `customerId` | - |
| GET | `/nurse-items/{customerId}` | 查客户已购项目（含状态） | 路径 `customerId` | `List<CustomerNurseItemVO>` |
| POST | `/nurse-item/renew` | 续费 | Query：`id`、`addCount` | - |
| DELETE | `/nurse-item/remove/{id}` | 移除客户项目 | 路径 `id` | - |
| POST | `/nurse-item/buy` | 单独购买项目 | JSON：`CustomerNurseItemAddDTO` | - |

> 注意：设置级别的实际路径是 `POST /admin/customer?levelId=x`，请求体例如 `1`（与设计文档中的 `/level/set` 不一致）。

## 3. 核心业务逻辑（CustomerNurseItemServiceImpl）

### 3.1 设置护理级别 `setCustomerLevel(customerId, levelId)`（事务）

1. 校验客户存在；
2. 校验客户当前**没有**护理等级：查 `customer_nurse_item` 中该客户 `level_id IS NOT NULL` 的记录数 > 0 则抛异常（`该客户已拥有护理等级，请先移除现有等级`）；
3. 查 `nurse_level_item` 中该级别下所有项目，若为空抛异常（`该护理等级下未配置任何项目，无法设置`）；
4. 批量插入 `customer_nurse_item`：
   - `level_id = 级别ID`（标记为等级绑定）；
   - `nurse_number = 1`（默认 1 次）；
   - `buy_time = 今天`；`maturity_time = 今天 + 3 个月`。

### 3.2 移除护理级别 `removeCustomerLevel(customerId)`（事务）

删除该客户所有 `level_id IS NOT NULL` 的记录（物理删除），**保留单独购买的记录**。

### 3.3 查询已购项目 `listCustomerNurseItems(customerId)`

查询该客户全部项目记录，批量补项目名（`nurse_content.nursing_name`），逐条计算状态：

| status | 含义 | 判断 |
| --- | --- | --- |
| 1 | 正常 | 次数 > 0 且未到期 |
| 2 | 欠费 | `nurse_number <= 0` |
| 3 | 已到期 | `maturity_time < 今天` |

### 3.4 续费 `renewItem(id, addCount)`（事务）

1. 记录不存在抛异常；
2. `nurse_number += addCount`；
3. 有效期：未到期则在原到期日 **+3 个月**，已到期则从今天 **+3 个月**。

### 3.5 单独购买 `buyItem(dto)`（事务）

- `level_id = null`（与等级赠送区分）；
- `nurse_number = addCount`；`buy_time = 今天`；
- `maturity_time`：传了用传入值，否则默认 `今天 + 1 个月`。

### 3.6 移除单个项目 `removeItem(id)`

`removeById`（当前为物理删除，见注意事项）。

## 4. 数据表

`customer_nurse_item`（12_biz_customer_nurse_item.sql）：`id、customer_id、item_id、level_id(可空)、nurse_number、buy_time、maturity_time、is_deleted`。

## 5. 注意事项

1. 状态定义与"管家日常护理"模块（12 文档）不一致：本模块 `2=欠费、3=到期`；管家模块 `2=已到期、3=次数不足`，同一 `CustomerNurseItemVO` 两套语义，建议统一；
2. `removeCustomerLevel/removeItem` 为物理删除；
3. "已设置等级"的判定基于 `customer_nurse_item.level_id`，而不是客户表字段（客户表当前没有级别列）。
